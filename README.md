# 动漫周刊

适配手机和电脑的动漫发现应用，收录国漫与日漫，新用户默认查看全部动漫，也可分别筛选。保留已有用户的分类偏好与收藏。使用 Node.js 22+，运行时无第三方依赖，无需 API Key。

## 启动

```sh
npm start
```

电脑打开 http://localhost:3000。手机访问：双击「开启手机访问.cmd」，首次自动下载并验证 Cloudflare 官方客户端；保留窗口，电脑网页点击「在手机上使用」，扫码或复制生成的 HTTPS 网址。支持手机流量和不同 Wi-Fi，无需配置路由器。手机连接器固定使用 3000 端口。

## 已实现

- 四平台真实数据采集，服务运行期间每 6 小时刷新，支持手动更新。
- 哔哩哔哩国创 / 番剧近 7 天榜；腾讯动漫热搜榜；爱奇艺动漫实时热度榜；优酷动漫 / 日番热度榜和推荐。
- 国漫 / 日漫 / 全部切换，按产地分类。中文版日漫仍归日漫；未知地区、欧美动画、真人特摄暂不收录。
- 平台与题材组合筛选；日漫补充恋爱、校园、日常、治愈、运动、音乐、推理、异世界等题材。
- 搜索、排序、网格 / 列表切换、作品详情、正版播放入口，记住内容分类偏好。
- 追番收藏保存在当前浏览器，刷新或重启仍保留。暂不支持跨设备同步。
- 按北京时间每周一生成周次，本周存档持续更新，过去周次保留，不补造历史数据。
- 上游出错时保留最近成功数据，并在界面标注来源状态与缓存时间。
- PWA 清单、手机主屏幕图标、离线页面与已访问榜单缓存。
- 周刊日历支持选择 2000—2100 年的年份、月份和具体日期，也可直接输入日期；以北京时间将所选日期定位至周一开始的周榜。日历标记有记录的日期，没有存档的周明确提示暂无榜单。
- 桌面侧边导航与手机悬浮底栏统一设计，提供发现、追番和日历入口；日期入口保留完整年份，跨年周刊也能清楚辨认。
- 每日更新导航：按北京时间显示本周周一至周日的动漫排期，默认今天；支持平台、国漫 / 日漫、题材、搜索和只看追番。卡片直接显示更新时刻（如 10:00）及会员说明；平台只公布更新日时，显示「周二更新」这类明确日期，不再使用「时间待定」。状态区分平台排期、已更新、已完结和延期。
- 每日排期接入四家官方日历：B站国创 / 番剧时间表、腾讯视频每日更新（逐日读取七天）、优酷频道每日更新表、爱奇艺追番表。仅保留已确认中国 / 日本产地的动画，优酷未知产地可由同名作品的已核实平台元数据补充，冲突与未知地区不收入。每 6 小时读取，保存至 `data/schedule.json`，来源失败时保留缓存并标明状态。
- 腾讯日历保留当天会员更新时间和完整抢先看说明；优酷每日更新表自带每条作品的更新时刻与「SVIP 抢先 / VIP」说明，直接采用；爱奇艺追番表只返回星期与首播时间，卡片会标出「周二更新」这类更新日，能取得首播钟点时显示具体时间。三家日历条目标为「平台排期」，不把当前集数、已经过了播出时间或日历收录当成「已更新」证据。点击作品可查看对应平台、日期、更新时刻和会员说明。

## 榜单口径

四个平台没有一致的周播放量指标，只有 B 站源明确是近 7 天榜。其余为当次采集的热度或推荐，按周保存快照，并非官方跨平台周榜。热度、评分和累计追番数分别标注，不相互冒充。

综合排序对各平台名次计算 `1 / (60 + rank)` 后按同名、同产地作品相加，优酷推荐项贡献 `0.35 / 100`。在所选内容分类中将最大值归一为 100 分，作为本站「榜单指数」，名次从 1 开始；各平台原榜位保留。不同季数分别展示；标签包括平台标签和本地作品分类，可能不完整。

B站番剧榜还含有欧美动画和真人特摄，因此只保留已确认的日本动画系列；爱奇艺读取产地字段；腾讯使用已确认系列清单；优酷结合平台日番榜、国漫栏目和系列清单。产地清单在 `src/sources.mjs` 维护，题材选项在 `public/catalog.js`，本地作品题材在 `public/app.js`。历史存档与旧国漫收藏继续可用，日漫从此次实际采集开始收入。

## 手机正式使用与部署

临时手机网址由 Cloudflare Quick Tunnel 提供，连接确认成功后才显示二维码。电脑、应用与连接窗口须保持运行；关闭后链接失效，重新启动会生成新网址。它适合临时使用，不保证稳定性或长期保留，部分网络可能无法访问 Cloudflare。访问状态与二维码不进入离线缓存，断线后会提示重新开启。无需账号，网址对知晓链接的人开放，收藏仍保存在各自浏览器。首次安装后可在手机菜单添加到主屏幕。

长期使用建议部署到固定 HTTPS 域名（`PUBLIC_URL=https://你的域名`），这样主屏幕入口和收藏始终对应同一网址。正式 PWA 安装和离线能力需要 HTTPS（开发时 localhost 除外）。

将整个目录部署到支持 Node.js 常驻服务的主机，启动命令为 `npm start`，通过反向代理配置 HTTPS 域名，并为 `data/` 配置持久存储。建议使用进程管理器自动重启。纯静态托管无法运行采集服务；自动更新依赖服务运行和上游可访问性，PWA 关闭后不会在手机后台自行采集。

`data/current.json` 保存最近数据；`data/week-YYYY-MM-DD.json` 保存周榜。无需账号或抓取登录态。公开页面结构可能变化，对应解析器在 `src/sources.mjs`。图片代理只允许预设平台域名，限制重定向、类型和大小。

## 验证

```sh
npm test
```

使用 Node.js 内置测试覆盖国漫 / 日漫地区过滤、中文版产地识别、欧美及真人特摄排除、原始榜位保留、推荐与榜单区分、不同季数及产地合并规则、分类排名，以及北京时间周边界。

`scripts/browser-check.mjs` 用 Playwright 检查桌面 / 手机布局、四平台日漫筛选、恋爱 / 音乐等题材、搜索、国漫与日漫收藏保留、分类偏好、详情、历史周榜和离线浏览。先启动服务，需要本机已有 Chrome；可用 `npm install --no-save playwright` 安装验证工具，再运行 `node scripts/browser-check.mjs`。验证截图保存在 `output/playwright/`。

包含临时公网连接启动器；尚未配置固定公网域名、线上托管、通知推送或应用商店上架。

`node scripts/calendar-check.mjs` 检查年份、月份、闰日、跨年周刊、无存档提示及 390px / 320px 手机布局和离线日历。历史日期使用隔离的浏览器测试数据，不写入实际档案。

`node scripts/schedule-check.mjs` 核对七天排期与真实接口一致，检查筛选、收藏、详情、来源失败重试和 390px / 320px 手机及离线排期。需要 Chrome 与 Playwright；截图保存在 `output/playwright/daily-*.png`。单元测试另覆盖延期、跨年排期和旧缓存不挪用日期。

`node scripts/probe-all-calendars.mjs` 可独立检查四平台真实日历采集和产地过滤结果，网络诊断数据写入 `output/research/`，不修改正式榜单与存档。
